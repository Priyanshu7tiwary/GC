# Verified CAT question-paper PDFs

This bundle contains 24 slot-wise PDF papers for CAT 2017–2025, downloaded from Collegedunia’s year-specific paper pages. Each downloaded PDF was checked for a PDF signature and extracted text identifying the CAT year and slot. The PDFs are copied to `frontend/public/cat-papers/` so the frontend image serves them locally. `manifest.csv` records source URL, local asset path, byte size, SHA-256 digest, and retrieval status.

## Coverage limit

No official CAT question papers for 2011–2016 were publicly released; reliable CAT preparation sources describe copies from those years as memory-based or reconstructed. Those unverified copies are not being presented as official papers or inserted as tests. The gap is recorded in `unavailable_official_years.csv` and in Flyway migration V5.

Source for official-release boundary: [Bodhee Prep CAT paper archive](https://bodheeprep.com/cat-question-paper-previous-years-pdf). Official-PDF host pages: [CAT 2017](https://collegedunia.com/exams/cat/question-paper-2017) through [CAT 2025](https://collegedunia.com/exams/cat/question-paper-2025).

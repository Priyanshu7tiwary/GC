# CAT official question papers (source record)

The 24 slot-wise CAT 2017–2025 paper PDFs that used to live here, and in `frontend/public/cat-papers/`, have been removed. The papers are now playable tests built from their extracted text; see `resources/cat_pyq_answer_keys/README.md`. `manifest.csv` still records where each PDF came from and its SHA-256, in case the originals are needed again (for example, to re-run `papers/extracted/extract_cat_papers.py`).

## Coverage limit

No official CAT question papers for 2011–2016 were publicly released. Reliable CAT preparation sources describe copies from those years as memory-based or reconstructed. Those unverified copies are not presented as official papers or offered as tests. The gap is recorded in `unavailable_official_years.csv`.

Source for the official-release boundary: [Bodhee Prep CAT paper archive](https://bodheeprep.com/cat-question-paper-previous-years-pdf). Original PDF host pages: [CAT 2017](https://collegedunia.com/exams/cat/question-paper-2017) through [CAT 2025](https://collegedunia.com/exams/cat/question-paper-2025).
